# Manual-Testing-of-Justdial-Application


## Project Overview

This project is about **Manual Testing of the Justdial Web Application**.

The main features tested are:

* Home Page
* Search
* Location
* Search Results
* Filters
* Sorting
* Business Details
* Ratings & Reviews
* Contact/Enquiry

## Testing Type

**Manual Testing**

## Test Cases

The project contains test scenarios and test cases with:

* Test Case ID
* Test Steps
* Expected Result
* Actual Result
* Status
* Severity
* Priority
